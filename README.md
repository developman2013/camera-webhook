# Camera Webhook

Небольшой Windows tray-agent, который отправляет настраиваемые REST-запросы при включении и выключении камеры.

## Установка

Скачайте `CameraWebhook-Setup-*.exe` из [последнего релиза](https://github.com/developman2013/camera-webhook/releases/latest) и запустите его. Установка выполняется для текущего пользователя и не требует прав администратора.

После запуска откроется окно настройки. В дальнейшем оно доступно двойным щелчком по значку Camera Webhook в системном трее.

## Возможности

- один агрегированный статус для всех камер и приложений;
- отдельные URL, HTTP-метод, заголовки и тело для событий включения и выключения;
- методы `POST`, `PUT`, `PATCH`, `GET` и произвольный HTTP-метод;
- шаблоны `{{event}}`, `{{timestamp}}`, `{{machine}}` в теле и значениях заголовков;
- автозапуск при входе текущего пользователя в Windows;
- таймаут REST-запроса 15 секунд и уведомление об ошибке;
- per-user установка без UAC.

Пример тела запроса:

```json
{
  "event": "{{event}}",
  "timestamp": "{{timestamp}}",
  "machine": "{{machine}}"
}
```

Заголовки задаются JSON-объектом:

```json
{
  "Authorization": "Bearer secret",
  "X-Computer": "{{machine}}"
}
```

Настройки хранятся в `%LOCALAPPDATA%\CameraWebhook\config.json`. Секреты в заголовках сохраняются как обычный текст с правами текущего пользователя.

## Как определяется состояние камеры

Агент проверяет записи `CapabilityAccessManager` текущего пользователя, которые Windows обновляет при использовании камеры приложениями. Переход считается включением, когда хотя бы одно приложение использует камеру, и выключением — когда активных приложений больше нет. Начальное состояние после запуска не вызывает запрос.

Этот механизм рассчитан на приложения, использующие стандартные Windows camera APIs. Драйверы или приложения, которые обращаются к устройству в обход механизмов конфиденциальности Windows, могут не отражаться в этих записях.

## Сборка

Требуется Windows и .NET 8 SDK:

```powershell
dotnet build CameraWebhook.sln -c Release
dotnet test CameraWebhook.sln -c Release
```

GitHub Actions собирает проект при каждом push/PR. Push тега вида `v1.0.0` публикует self-contained x64 установщик в GitHub Releases.
